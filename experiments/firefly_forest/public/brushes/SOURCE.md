# Brush stroke sources

Four unmodified PNGs from Dino0040's **~100 grunge brushstrokes and splatters set**, published November 7, 2020 on OpenGameArt.

- Source: https://opengameart.org/content/100-grunge-brushstrokes-and-splatters-set
- Download: https://opengameart.org/sites/default/files/grunge_brushes.zip
- License: CC0 1.0 — https://creativecommons.org/publicdomain/zero/1.0/
- Original files: `grunge_brushes/increased_opacity/brush004.png`, `brush009.png`, `brush020.png`, `brush025.png`.

At startup the browser rotates the vertical brush images onto the splat's major axis, resamples each to a padded 256 × 256 mask and uploads alpha only. Color comes from each forest splat. Rust generates an averaged mip chain for distant strokes.
