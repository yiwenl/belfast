# Blocks1 Implementation Plan

> Execute inline using the executing-plans and verification-before-completion workflows.

**Goal:** A runnable template-based blocks1 port with reusable GPU fluid simulation.

**Architecture:** Shared `belfast::fluid` owns the solver and a stable output buffer.
The experiment owns emitters, compute particles, textured cube drawing and shadows.

**Tech Stack:** Rust, wgpu 30, WGSL, wasm-bindgen, Vite, Tweakpane 4.

**Spec:** ../specs/2026-10-28-blocks1-design.md

## Constraints

No hand detection or mouse forces. Keep existing experiments unchanged. Reuse
template lifecycle/watcher and existing Belfast GPU helpers. Use original assets.

## Review focus

- Validate finite settings, dimensions, timestep and splats before GPU writes.
- No storage read/write aliasing, including odd pressure iteration counts.
- Stable output binding across steps/reset; no stale pressure after reset.
- Large frame gaps and pause/resume cannot cause unstable integration.
- Browser resize, errors, HMR and disposal release resources correctly.
